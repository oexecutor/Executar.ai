# Dependency security remediation — 2026-07-27

## Scope

This change removes the vulnerable ESLint 8 dependency chain from the root
tooling and `web`, and updates the MCP SDK production dependency that retained a
vulnerable Hono adapter.

No application feature, route, API contract, persistence rule, MCP
authentication rule, OAuth flow, Vault behavior, Journal behavior, or 3–9–36
workflow rule changes in this remediation.

## Audit evidence

Audits were run from clean installs generated by the committed lockfiles.

| Workspace | Dependency scope | Before | After |
| --- | --- | ---: | ---: |
| root | all | 14 high, 2 moderate | 0 |
| root | production | 2 moderate | 0 |
| `web` | all | 14 high | 0 |
| `web` | production | 0 | 0 |

Commands:

```sh
npm ci
npm audit --json
npm audit --omit=dev --json
npm --prefix web ci
npm --prefix web audit --json
npm --prefix web audit --omit=dev --json
```

All four final reports returned zero `info`, `low`, `moderate`, `high`, and
`critical` vulnerabilities.

## Direct dependency changes

- ESLint: `8.57.1` → `10.8.0`
- `@typescript-eslint/eslint-plugin`: `7.18.0` → `8.65.0`
- `@typescript-eslint/parser`: `7.18.0` → `8.65.0`
- `eslint-config-prettier`: `9.1.0` → `10.1.8`
- `eslint-plugin-react-hooks` (`web`): `5.2.0` → `7.1.1`
- `@modelcontextprotocol/sdk`: `1.29.0` → `1.30.0`
- pins the SDK's `@hono/node-server` adapter to the secure `2.0.12`
- adds compatible direct flat-config dependencies `@eslint/js` and `globals`

The legacy `.eslintrc.json` files were replaced by ESLint flat configuration.
The established lint policy remains the same: recommended JavaScript and
TypeScript rules, React rules-of-hooks and exhaustive-deps in `web`, Prettier
conflict suppression, and zero allowed warnings.

## Rollback

Revert the remediation commit and redeploy the preceding known-good production
deployment. A rollback restores the prior dependency findings, so it is only an
emergency compatibility measure; the preferred response to any later issue is
a forward fix on the secured dependency graph.
