## Show HN

**Título** (80 caracteres, regra do HN): `Show HN: EXECUTA.AI – execução de projeto com MCP nativo, não outro board`

**Corpo:**

> Construí o EXECUTA.AI depois de cansar de ferramentas de PM que exigem
> que eu decida a estrutura inteira do projeto antes de começar a
> trabalhar de verdade. A ideia central: você joga contexto bruto (notas,
> ideias, um brief incompleto) e o sistema estrutura em fases, áreas e
> ações — sempre com uma próxima ação visível, evidência ligada a cada
> decisão, e histórico que sobrevive a você fechar o notebook por uma
> semana.
>
> Duas coisas que talvez interessem aqui especificamente:
>
> 1. **MCP nativo, não um plugin por cima de um chatbot.** O servidor MCP
>    (`/mcp`) usa os mesmos dados e regras de autorização do app web — não
>    é uma API paralela mal mantida. Se você já usa Claude com MCP para
>    outras coisas, dá para conectar o EXECUTA.AI direto.
> 2. **Desenho para carga cognitiva, não para feature completa.** Um
>    workflow principal por dia, no máximo três passos visíveis por
>    tarefa. Foi uma escolha de produto deliberada, não falta de tempo
>    para construir mais opções.
>
> É cedo — estou abrindo para um grupo pequeno agora, não lançamento
> amplo. Feedback bruto é bem-vindo, principalmente "isso não resolveu
> meu problema porque X".
